# Attribution

This skill adapts ideas and the component-authoring rules from BuilderIO Mitosis
(https://github.com/BuilderIO/mitosis), used under the MIT License. Mitosis is a
compiler that turns one component source into native code for many frameworks. This
skill does not bundle Mitosis. It borrows its one-canonical-source principle for a
cross-project component library, and summarizes its documented gotchas and ESLint
rules in `references/mitosis.md`.
